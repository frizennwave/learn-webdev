# Learn Web Development 🚀

Repository ini berisi catatan, latihan, dan proyek yang mendokumentasikan perjalanan belajarku dalam menguasai pengembangan web (*web development*) dari dasar hingga tingkat lanjut.

## 📌 Latar Belakang

Perkembangan dunia *web development* sangat pesat dan membutuhkan pemahaman yang kuat, mulai dari konsep dasar *client-side* hingga arsitektur *backend* yang kompleks. Repository ini dibuat sebagai wadah dokumentasi mandiri untuk mencatat setiap langkah pembelajaran, eksperimen kode, dan pembuatan proyek secara terstruktur.

Progres pembelajaran dalam repository ini dirancang mencakup ekosistem *Full-Stack Web Development* modern secara bertahap:

1. **JavaScript** — Menguasai dasar-dasar bahasa pemrograman JavaScript, struktur data, konsep asinkron, serta API peramban (*browser*).
2. **Node.js** — Memahami *runtime environment* JavaScript di sisi *server*, manajemen modul, dan pemrosesan I/O.
3. **Express.js** — Membangun RESTful API, penanganan *middleware*, autentikasi, serta manajemen *routing*.
4. **PostgreSQL** — Mempelajari basis data relasional, perancangan skema database, kueri SQL, serta integrasi dengan *backend*.
5. **React.js** — Membangun antarmuka pengguna (UI) berbasis komponen yang reaktif dan dinamis di sisi *frontend*.
6. **Next.js** — Mengembangkan aplikasi React dengan *Server-Side Rendering* (SSR), *Static Site Generation* (SSG), dan *App Router*.
7. **Nest.js** — Menerapkan arsitektur *backend* enterprise berbasis TypeScript yang terstruktur, modular, dan *scalable*.
